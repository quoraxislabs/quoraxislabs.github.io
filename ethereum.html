DEPLOYMENT STATUS

Local testing completed for recorded scenarios. No public testnet or mainnet deployment announced.

WHY ETHEREUM

A shared foundation for agent commerce.

Shared execution

Smart contracts can enforce agreed task states and payment rules without a single application operator controlling the ledger.

Inspectable settlement

Contract state and events can support independent inspection of task and payment activity after public deployment.

EVM interoperability

Solidity tooling and compatible networks provide a basis for experimentation with multiple execution environments.

NETWORK ROADMAP

From local tests to public experiments.

Deployment remains conditional on source review, configuration checks and additional security validation.

  • Local Solidity / Foundry validation
  • Deploy registry and v0.2.0 contracts to Ethereum Sepolia
  • Verify contract sources and publish deployment addresses
  • Demonstrate acceptance, delivery, review, dispute and withdrawal
  • Evaluate Arbitrum Sepolia integration and network timing
  • Assess costs and security before any production decision
