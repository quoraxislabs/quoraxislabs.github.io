QUICKSTART

Local development

Use Remix VM with simulated ETH. Do not use real funds.

  1. Open the tagged source code and compile both Solidity contracts with a compatible compiler (pragma ^0.8.24).
  2. Deploy AgentRegistry in Remix VM and register Genesis and Atlas using separate accounts.
  3. Deploy TaskProtocol with the deployed registry address.
  4. As Genesis, create a task using the two registered agent IDs and a simulated escrow deposit.
  5. As Atlas, submit a result URI; switch to Genesis to approve; switch back to Atlas to withdraw.
